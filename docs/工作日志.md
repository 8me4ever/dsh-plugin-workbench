## 2026-08-28 · BOSS直聘 API 通道攻坚 ✅(重大突破)

### 背景

用户在公司电脑登录 BOSS直聘,尝试用 playwright 页面自动化抓取,遇到多层反爬。

### 排障历程(踩坑全记录)

| 问题 | 根因 | 解决 |
|---|---|---|
| `check` 报 TargetClosedError 崩溃 | 系统 Chrome 正在运行,`channel="chrome"` 触发单实例冲突,新实例退出 | 改用 playwright 自带 Chromium(`python -m playwright install chromium`),与系统浏览器隔离 |
| 页面加载后跳 `about:blank` | BOSS 反爬检测自动化浏览器(页面 JS 自跳转并关闭) | 确认页面自动化**此路不通**,转向 API 通道 |
| API 直接请求 code=37「环境异常」 | 缺少浏览器请求头(UA/Referer/Origin/Sec-Fetch) | 补全完整浏览器头 → **code=0 成功拿到岗位 JSON** |
| 连续请求第 4 次起 code=37 | BOSS 请求次数风控(短时间超限) | 指数退避重试 + 页间 3s 限速;风控后打开窗口刷新会话 token 解除 |

### 最终方案:BOSS 官方搜索 API

```
GET https://www.zhipin.com/wapi/zpgeek/search/joblist.json
  ?scene=1&query=数据分析&city=101010100&page=1&pageSize=30
Headers: UA + Accept + Referer(搜索页) + Origin + Sec-Fetch-*
登录态: data/.boss_profile(用户手动扫码一次,持久化)
```

- 返回完整结构化字段:`jobName / salaryDesc / skills / jobExperience / jobDegree / cityName / brandName / brandStageName / welfareList` 等,无需解析 HTML。
- **实测:60 条「数据分析·北京」真实岗位抓取成功**(2 页 × 30),含字节跳动、百度、快手、作业帮、去哪儿网等。

### 交付

- `scripts/boss.py` 重写为 API 通道:`check`(API 探测登录态)/ `fetch`(抓取多页,带重试+限速)。
- `scripts/boss_open.py`:只开窗口、用户手动登录/刷新会话(登录态存独立 profile)。
- `main.py fetch-boss`:BOSS 结构化数据 → 组装 JD 文本 → 解析打分入库(`source=boss`)。
- **画像/打分优化**:加分技能扩充到 27 项(AB测试/ETL/数据仓库/spark/hive 等工程技能),`_skill_score` 算法改为「命中数 + 核心权重占比」双因子,解决技能列表变长后分数稀释问题;company_plus 增加「已上市/D轮」。
- 测试 18/18 通过。

### 当前数据

- BOSS 分级:1 个 A(字节跳动数据分析师 79.8 分)+ 7 个 B + 52 个 C。

### 1. 修复 import_json 往返不幂等 bug(提交 `96b88d7`)

- **现象**:重建本地库后再导出,按 score 排序的**最后一条**岗位的 reasons/details 丢失(实测 Loops 岗位过滤原因被清空)。
- **根因**:`import_json` 循环内 `upsert_job` 会触发 `export_json`,但「恢复打分」的 UPDATE 发生在最后一条导出之后,且循环结束未再导出。
- **修复**:`commit` 后补一次 `export_json`;新增回归测试 `test_import_reexport_preserves_reasons_and_details`。

### 2. BOSS直聘 V2 采集器(登录与抓取解耦)

- **结论**:BOSS直聘 反爬强、需登录态,「半自动」可行——登录一次性手动扫码,抓取全自动复用登录态(cookie 持久化)。
- **环境踩坑(重要)**:
  - 本机 Clash 的 fake-ip DNS 把 `zhipin.com` 错解析到百度(浏览器拿到百度内容);用 `--proxy-server=direct://` + `--host-resolver-rules` 强制直连真实 IP 绕过。
  - BOSS 登录页有安全校验,自动化浏览器(`navigator.webdriver=true`)会触发「每 2 秒刷新」的循环校验;需隐藏 webdriver 特征。
- **交付**:`scripts/boss.py` 三个命令——`check`(查登录态)、`login`(开窗口等手动扫码,一次性)、`fetch`(检查已登录才抓取,未登录直接提示)。
- **状态**:网络绕过 + 登录解耦已就绪;**待用户扫码登录一次后 `fetch` 即可跑通**。
